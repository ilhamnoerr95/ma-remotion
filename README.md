# Remotion + OmniVoice video pipeline

```
app/        Remotion project. Composition "Episode1" is built from app/src/episodes/ep1.json.
episodes/   Narration scripts (episodes/ep1/narration.txt: one line = one clip = one image).
tts/        OmniVoice narration generator (generate.py), narrator voice (tts/voice/), requirements.
templates/  Reference copies of the official Remotion templates (not installed).
comfyui/    Optional client for generating images on a ComfyUI server (see bottom).
setup.sh    One-shot setup for macOS/Linux.
```

Remotion packages are pinned to `4.0.543`. Upgrade together: `cd app && npx remotion upgrade`.

## Machine requirements

| Part | Needs |
|---|---|
| Remotion render | Node 20.19+ / 22.13+ / 24+, about 1 GB disk (node_modules + Chrome), more CPU cores = faster render |
| OmniVoice | Python 3.10 to 3.13 (not 3.14), about 5 GB disk (venv 1.2 GB + model 2.5 GB+), NVIDIA GPU recommended. Apple Silicon (MPS) works. CPU only works but is slow |

## Setup on a new machine

macOS / Linux:

```bash
git clone <your-repo-url> remotion && cd remotion
./setup.sh              # Remotion app + OmniVoice (use ./setup.sh --no-tts to skip OmniVoice)
```

Windows (PowerShell, or use WSL and the commands above):

```powershell
cd app; npm ci; cd ..
py -3.13 -m venv tts\.venv
tts\.venv\Scripts\activate
pip install torch==2.8.0+cu128 torchaudio==2.8.0+cu128 --extra-index-url https://download.pytorch.org/whl/cu128
pip install -r tts\requirements.txt
```

The Windows commands and the Linux/CUDA branch of `setup.sh` were written from the OmniVoice README and have not been run. The macOS (Apple Silicon) path was run on the original laptop.

## Make an episode

Activate the TTS environment first (macOS/Linux): `source tts/.venv/bin/activate`

1. **Script.** Edit `episodes/ep1/narration.txt`. One non-empty line = one clip = one scene. Lines starting with `#` are comments.
2. **Images.** Put them in `app/public/assets/ep1/images/` named by line number: `01.jpg`, `02.jpg`, ... (`png`, `jpeg`, `webp` also work). Scenes without an image show the narration text as a draft card.
3. **Narrator voice (once).** `python tts/generate.py --make-voice`, then listen to `tts/voice/narrator.wav`. Repeat until you like it, then commit `tts/voice/` so every machine uses the same voice. Change the style with `--instruct "male, low pitch, american accent"`.
4. **Narration.** `python tts/generate.py`. It generates only missing or changed lines, then updates `app/src/episodes/ep1.json` (durations, image links). Run it again after any script, image or voice change. `--sync-only` skips the model and only relinks images and durations.
5. **Music and sound effects (optional).** Put `music.mp3` in `app/public/assets/ep1/` and set this in `app/src/episodes/ep1.json` (`generate.py` keeps it):
   ```json
   "music": { "src": "assets/ep1/music.mp3", "volume": 0.12 }
   ```
   Check each file's license before use (CC0, Pixabay Content License, or CC BY with attribution).
6. **Preview.** `cd app && npm run dev`, open `http://localhost:3000`, pick `Episode1`.
7. **Render.** `cd app && npx remotion render Episode1 out/ep1.mp4`. The first render downloads Chrome (about 150 to 600 MB).

Scene timing: each scene lasts its narration length plus `padding` (default 0.5 s, editable in the json), with a 10-frame crossfade into the next scene and a slow zoom on every image.

Subtitles are not generated by Remotion. They are part of the images, so each image must show the same text as its line in `narration.txt`.

## Adding another episode

Copy `episodes/ep1` to `episodes/ep2`, add `app/public/assets/ep2/images/`, run `python tts/generate.py --episode ep2`, then register it in `app/src/Root.tsx` by importing `./episodes/ep2.json` and calling `registerEpisode("Episode2", ep2)`.

## Optional: ComfyUI for images

Start ComfyUI on the other machine with `python main.py --listen 0.0.0.0 --port 8188`. It has no authentication, so use a trusted network, Tailscale, or an SSH tunnel.

```bash
cp .env.example .env                       # set COMFYUI_URL
node --env-file-if-exists=.env comfyui/generate.ts --ping
node --env-file-if-exists=.env comfyui/generate.ts comfyui/workflows/image.json \
  --set 6.text="a red fox in snow" --set 3.seed=42
```

Export workflows with **Save (API Format)** into `comfyui/workflows/`. `6` and `3` are node IDs from your workflow JSON. Results go to `COMFYUI_OUT_DIR` (default `app/public/assets`).
